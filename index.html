the question

When does a model follow the wrong instruction?

I'll write a small set of prompts where instructions conflict or the context is misleading. For each one, I decide the correct behavior before running anything, then score every response the same way.

The goal is a narrow, testable claim, with failure cases and limitations written up honestly. Not a sweeping conclusion drawn from a handful of prompts.
